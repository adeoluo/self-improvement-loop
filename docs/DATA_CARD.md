# Data Card - Self Improvement Loop

## Source
- **Fully synthetic.** Puzzles are generated in-process by a seeded random generator. There is
  no external dataset, download, or network access.

## Composition
- Each puzzle is a triple `(start, target, budget)`. `start` is drawn from `0..60`, `target`
  from `0..120`, and the default budget is 6 steps.
- Only puzzles that the breadth-first oracle can solve within budget are kept, so every
  instance has a known solution.
- Default splits: 200 training puzzles and 120 test puzzles. Splits are disjoint by `(start,
  target)` by construction, so held-out accuracy measures generalization.

## Labels and supervision
- There are no human labels. The training signal is the verifier: a trace is a valid training
  example only if it reaches the target in bounds and within budget.
- Rationalization examples are produced by the oracle's shortest solution for puzzles the policy
  cannot yet solve by sampling.

## Provenance and licensing
- Generated by this repository's code under the MIT license. No third-party data is included.

## Filtering and contamination
- Unsolvable-within-budget pairs are filtered out during generation.
- Train and test splits are disjoint; the test split is drawn from a different seed offset and
  excludes any `(start, target)` present in the training split.

## Known limitations
- The value range and action set are deliberately small. The distribution is not meant to
  resemble natural reasoning data; it exists so the verifier and oracle can be exact.
